# LLM Reference Data

## Website Technical Details - Platform:
- Adobe Commerce (Formerly Magento) Cloud - version 2.4.5 (currently in process of upgrade to 2.4.8)
- Integration with Microsoft Dynamics d365 ERP: Order information, customer information, and product information, inventory and pricing syncs. 
- Marketing flows powered by Klaviyo for outbound Email campaigns, triggered surveys, and more
- CDN: Fastly
- Firewall / site security: Cloudfare
